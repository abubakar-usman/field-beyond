# Project skills

| Skill | Use for |
|---|---|
| `geo-pipeline/` | Adding data sources, preprocessing, features (coordinate, resolution and provenance rules) |
| `run-app/` | Running, testing and deploying locally or on the GCP VM |
| `scientific-copy/` | Wording rules for any user-facing text |
| `design-taste-frontend/` | **Not installed yet.** Open-source taste-skill (github.com/Leonxlnx/taste-skill) for frontend design quality. Install: `npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend` (check that repo's README for the current command), confirm it lands here, then commit it |
