# Wording rules

| Don't say | Say |
|---|---|
| discovered, new analog, new site | unlisted candidate, not in checked records |
| probability, confidence, likelihood, accuracy | configured similarity (terrain-v1) |
| "this place is like Mars" | "terrain resembles Jezero crater at 200 m scale" |
| matches the Martian environment | matches selected terrain measurements |
| safe to land / test here | (don't say it — out of scope) |
| AI found, model predicts | measured, compared, scored |
| (hiding missing data) | "not available" — always list it |

## Every candidate view must show
- The scale (e.g. 200 m pixels, 10 km window).
- Each feature's Earth value, target value, and tolerance.
- The main mismatch.
- Missing or unavailable evidence.
- Novelty label + which records were checked + date.
- Scoring version.

## Tone
Plain, specific, numbers with units. Avoid hype. Short sentences. Say what was measured, not what it means for science.
