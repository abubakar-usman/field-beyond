# Changelog

One line per meaningful change, newest first.

## 2026-11-15
- End-to-end check of the new frontend against the API (Moon and Mars, both regions, top-k, rescore, run records, exports, reviews). Fixed: the metric table hid tolerance and similarity on phones (they now wrap); the review form now says how to enable reviews when the API has no `DEMO_TOKEN`.
- New frontend design (Field Beyond, ported from a Figma Make/Vite prototype into the Next.js 16 app): landing page with 3D Moon and Mars globes (three.js), an explore screen whose targets, regions and API health come from `/api`, and a comparison screen that runs `POST /searches`, lists candidates, shows the Earth map, the metric table with both values and tolerances, the explanation, and the full evidence panel (records checked, provenance, review). A clicked or typed point is never scored itself; the UI offers the nearest prepared target on the same body, using that body's radius. Tailwind v4 (PostCSS), `next/font` for DM Sans and Space Grotesk. The old sidebar page is removed; every API endpoint is now reachable from the new UI, including the target profile (`GET /targets/{id}`), processing-run records (`GET /processing-runs/{id}`), a top-k choice, and weight sliders that call `POST /searches/{id}/rescore`. Fixed a map crash when the Earth map remounted before its style loaded.
- IAU Moon and Mars names can be imported from the USGS Gazetteer (`pipeline import-gazetteer`) into a gitignored catalog. Curated sites stay in `config/targets/`. The target list searches that catalog; a name is not scored until `pipeline target` builds its profile. Decision D-031.
